<p align="center">
  Echoa; kullanıcıların müzik dinleyebildiği, sanatçıları takip edebildiği, favorilerini ve çalma listelerini yönetebildiği bir müzik streaming platformudur.
</p>

<p align="center">
  Proje, <strong>ASP.NET Core Web API</strong> ve <strong>ASP.NET Core MVC</strong> olmak üzere iki uygulamadan oluşur. Kullanıcı yönetiminde ASP.NET Core Identity, API güvenliğinde ise JWT Authentication & Authorization kullanılır.
</p>

<h2>🔐 Yetkilendirme Akışı</h2>

<div align="center">

```text
Kayıt / Giriş
      ↓
ASP.NET Core Identity
      ↓
JWT Token Üretimi
      ↓
Rol ve Paket Claim'leri
      ↓
Bearer Token ile API İsteği
      ↓
Yetki ve Paket Kontrolü
```

</div>

<ol>
  <li>Kullanıcı ASP.NET Core Identity üzerinden kayıt olur veya giriş yapar.</li>
  <li>Başarılı giriş sonrasında Web API tarafından JWT üretilir.</li>
  <li>Token içerisinde kullanıcı, rol ve paket bilgileri taşınır.</li>
  <li>WebUI, yetki gerektiren isteklerde token'ı <code>Bearer</code> şemasıyla gönderir.</li>
  <li>Şarkı dinleme ve streaming isteklerinde paket seviyesi doğrulanır.</li>
</ol>

<h2>🧪 API Testleri</h2>

<p>Web API endpoint'lerinin kontrolleri Postman üzerinden gerçekleştirilmiştir. Test sürecinde özellikle aşağıdaki senaryolar doğrulanmıştır:</p>

<ul>

  <li>Rol ve paket seviyesine göre erişim kontrolleri</li>

  <li>Şarkı, sanatçı, tür ve çalma listesi endpoint'leri</li>
  <li>MP3 streaming ve HTTP Range istekleri</li>
</ul>
